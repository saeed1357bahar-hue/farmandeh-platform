# Farmandeh Platform Runtime v0.3 Patch

This patch upgrades the Foundation v0.2 static placeholder into a working local-first web runtime.

## Implemented now
- RTL + mobile safe area
- Command Center with clickable modules
- Internal navigation and Back -> Command Center behavior
- Farmandeh Studio: rename workspace/modules, show/hide modules, reorder modules
- Dark/light theme, accent color, corner radius, density
- Local persistence (localStorage)
- JSON export
- Basic PWA cache
- GitHub Pages deployment workflow

## Not implemented yet
- Real database/data engine
- Authentication / server sync
- Role permissions enforcement
- Form builder / workflow builder
- APK wrapper

## Patch rule
Overlay the contents of this ZIP onto the existing `farmandeh-platform` repository root.
