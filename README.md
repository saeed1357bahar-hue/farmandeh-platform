# Farmandeh Platform Foundation v0.2

Farmandeh Platform is a metadata-driven, multi-tenant, no-code/low-code application platform.

## Goal
Build configurable business and personal systems without rebuilding the application for each industry.

## Core principles
- Stable kernel, replaceable modules.
- Pages, forms, fields, workflows, permissions, themes and dashboards are configuration.
- Multi-user and server-ready architecture from the foundation.
- Every component is versionable and independently replaceable.
- Ordinary customization must not require editing source code.
- Farmandeh Studio is the main customization surface.
- Templates allow cloning the same platform for different industries.

## First template
Repair Shop / Automotive Electronics Service.

## Repository rule
After this foundation is committed, future development should modify individual files/modules instead of replacing the whole repository.
