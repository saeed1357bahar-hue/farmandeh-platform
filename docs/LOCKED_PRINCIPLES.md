# Locked Principles

1. No hard-coded single-industry architecture.
2. Every module can be enabled/disabled.
3. Every page can be edited.
4. Every form and field can be edited.
5. Every dashboard widget can be rearranged.
6. Theme properties are data-driven.
7. Navigation belongs to Kernel.
8. Back/system back behavior belongs to Kernel.
9. Multi-user is foundational.
10. Server sync is foundational.
11. Permissions are field/action/page/module addressable.
12. Templates are cloneable.
13. Configuration is exportable/importable.
14. Changes are versioned.
15. One faulty page/module must not require redesigning the platform.
